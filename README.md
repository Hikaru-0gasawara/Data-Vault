# Data-Vault

Personal vault for the files I want versioned and close at hand: game configs,
reference lists, and notes. Every folder is self-contained and carries its own
README.

## Contents

| Folder | What it is |
|--------|------------|
| [`games/`](games) | Configs and references for the games I play |
| [`games/cs2/`](games/cs2) | **Counter-Strike 2** — `autoexec.cfg` plus swappable crosshair presets |
| [`games/tft/`](games/tft) | **Teamfight Tactics** — registry of reference sites (JSON + CLI) and per-patch notes |

## Layout

```
games/
├── cs2/    CS2 .cfg files (autoexec + crosshairs)
└── tft/    data/ (sources.json), scripts/ (CLI), notes/ (per patch)
```
